LessonCanvas 개인정보 처리 안내

시행일: 2026년 8월 21일

먼저 알려드립니다. LessonCanvas는 교사가 자신의 기기에서 PDF 수업 자료를 열고 판서하는 도구입니다. 계정, 서버, 데이터베이스, 외부 AI가 없으며 앱 운영자는 사용자가 연 PDF와 판서 내용을 수집하거나 전송받지 않습니다.

1. 서비스의 데이터 처리 구조

선택한 PDF는 사용자의 브라우저 안에서만 읽습니다. PDF, 페이지별 판서, 선택한 콘텐츠 영역과 풀이 내용은 현재 브라우저 메모리에서 처리되며 LessonCanvas 운영자에게 전송되지 않습니다. 브라우저 탭을 닫거나 새로고침하면 현재 작업 내용은 사라질 수 있습니다.

2. 처리하는 개인정보 항목과 최소 수집

LessonCanvas 앱 코드는 이름, 학번, 이메일, 연락처, 주민등록번호, 위치정보, 학생 답안과 같은 개인정보를 수집하지 않습니다. 화면 배치 편의를 위한 좌측 메뉴 접힘 여부만 현재 탭의 세션 저장소에 저장하며 개인을 알아볼 수 있는 정보와 결합하지 않습니다.

3. 처리 목적

개인정보를 수집하거나 이용하지 않습니다. 사용자가 직접 선택한 PDF와 판서 입력은 수업 화면 표시와 판서 기능 제공 목적으로 사용자의 기기 안에서만 일시적으로 처리합니다.

4. 보유 기간과 삭제

운영자가 보유하는 개인정보는 없습니다. 현재 구현의 PDF와 판서 데이터는 서버에 보관되지 않으며 브라우저 탭을 닫거나 새로고침하면 삭제될 수 있습니다. 좌측 메뉴 접힘 설정은 해당 탭을 닫으면 브라우저가 삭제합니다. 즉시 지우려면 탭을 닫고 해당 사이트의 브라우저 데이터를 삭제할 수 있습니다.

5. 제3자 제공

LessonCanvas는 개인정보를 제3자에게 제공하지 않습니다. PDF, 판서 또는 학생 정보를 외부 AI 서비스로 보내지 않습니다.

6. 개인정보 처리 위탁과 국외 이전

LessonCanvas 앱 기능은 개인정보 처리를 외부 업체에 위탁하지 않으며 국외로 이전하지 않습니다. 향후 로그인, 클라우드 저장, 외부 AI 또는 별도 분석 서비스를 추가한다면 적용 전에 이 안내를 수정하고 필요한 동의와 보호조치를 마련합니다. 배포 호스팅 사업자가 접속 기록을 처리하는 경우에는 실제 배포 사업자와 계약 내용을 확인한 뒤 이 항목에 별도로 공개합니다.

7. 열람·정정·삭제·처리정지 요청

운영자가 보유하는 개인정보는 없지만, 데이터 처리에 관한 확인이나 권리 행사가 필요하면 아래 이메일로 요청할 수 있습니다. 요청 내용을 확인하고 관련 법령이 정한 절차와 기한에 따라 답변합니다.

8. 만 14세 미만 학생 정보 보호

LessonCanvas는 교사용 수업 도구이며 학생 계정을 만들거나 학생의 개인정보를 운영자에게 전송하지 않습니다. 교사는 학생 이름, 학번, 답안 등 식별 가능한 자료가 포함된 PDF를 불필요하게 열지 않아야 합니다. 수업상 꼭 필요한 경우에도 학교의 개인정보 처리 절차에 따라 최소한으로 사용하고, 가급적 이름과 학번을 가린 자료를 사용해야 합니다.

9. 안전성 확보 조치

  • PDF와 판서는 서버로 보내지 않고 브라우저 안에서 처리합니다.
  • 비밀번호, API 키와 같은 비밀정보를 프런트엔드 코드에 저장하지 않습니다.
  • 외부 AI, 광고 및 사용자 추적 코드를 사용하지 않습니다.
  • 배포할 때에는 HTTPS를 적용하고 배포 사업자의 보안 설정을 점검합니다.

11. 안내 변경

기능이나 데이터 처리 방식이 바뀌면 시행 전에 이 문서를 수정하고 앱에서 알립니다. 특히 서버 저장, 사용자 계정, 외부 AI 또는 학생 정보 수집 기능을 추가할 때에는 실제 처리 항목, 목적, 보유 기간, 제3자 제공 및 위탁 내용을 먼저 공개합니다.
